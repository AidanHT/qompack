## Shared contracts for drafting

1. **Evidence before representation.** Apply privacy/retention before persistence; denied secrets are not archived for an exactness claim. Permitted captured host payload is the immutable evidence boundary; it may be partial, redacted, truncated or unsupported media. It is not automatically the complete process/file output. Normalized text and summaries are derivatives with identity, transform version, coverage, fidelity and provenance. Keep old identities resolvable; exact deltas must round-trip.
2. **Publication and recovery.** Verify object durability before committing references and an ingestion frontier, then publish only checkpoints whose dependencies resolve. A transaction over indexes cannot transact external object files. Capture failure prohibits pointer replacement. Distinct host events with equal content stay distinct; missing event IDs/relationships remain unknown. Record event order separately from arrival order.
3. **State and authority.** Immutable observations feed a derived state view with user requirements, explicit decisions, tool observations, agent hypotheses and extracted candidates distinguished. Scope, conflicts, supersession, observed dependencies and uncertainty travel with each record. An agent declaration is a claim. A current-file read never substitutes for historical retrieval.
4. **Compatibility.** Evolve frozen schemas with a versioned compatible reader/adapter and old fixture retention; do not redefine existing hashes or change boolean/error semantics silently. `negknow.Descriptor.MatchKey` already excludes the reason; reuse it. Existing file/zstd/JSONL storage and exact indexes remain preferred unless evidence justifies a migration. No required SQLite/FTS5/SDK replacement.
5. **Lifecycle.** A committed event frontier can contain explicit gaps/in-flight work. Local compaction attempts are locally identified, correlated conservatively, and not fabricated host IDs. SessionStart reinjection cannot wait for PostCompact. Exclude Qompack injections/wrappers from independent primary evidence. Finalize the latest usable checkpoint under a bounded timeout.
6. **Additional context and coverage.** Serialize complete records, include wrappers/handles/report overhead, and count the assembled representation with an identified estimator. Tiny/zero budgets and oversized critical records produce explicit overflow plus recovery/coverage diagnostics. Essential exact exceptions/small spans are allowed. Coverage states: Qompack-included, archive-only, native-load-observed, expired/deleted, unknown; timestamps/epochs and fidelity accompany them. No claim of native completeness or model compliance; asynchronous load events cannot prove absence or exact bytes.
7. **Host boundary.** Observe, reinject and replace newly delivered results only through documented and target-tested adapters. No native-history rewriting, cuts, cache-marker manipulation or deletion of delivered results. Automatic veto defaults off; no optimization veto of manual compact. Lack of a recovery/proactive distinction prevents safe default automatic veto. No unsupported trigger dependency. Qompack remains a Claude Code plugin; no OpenAI product calls or Codex runtime port.
8. **Admission and trust.** One synchronous transformation pipeline captures durably before replacing, first Qompack-owned responses then a tested schema allowlist. Preserve status, stderr, diagnostics, interruption/media flags, counts and identifying spans in structured and displayed content. Self-contained capsules precede relative deltas; same-epoch prior delivery is insufficient baseline proof. Fresh owned responses can transform once, already-processed envelopes bypass repeat work. Changed failure signature/parser or uncertain capture resets delta eligibility. Unknown parsers/binary/multimodal outputs pass through; privacy denial follows privacy policy. Authorize before previews and expansion; hashes are not permissions, archived content is untrusted, and retrieval cannot replay commands or bypass denied reads.
9. **Policy and accounting.** Cadence/dirty-state/bounded maintenance work without native control or token/cache observations. Worker cancellation, quotas, bounded queues and recovery are explicit. Representation selection chooses at most one compatible representation with dependency closure and deterministic ties. No generic greedy guarantee or task oracle. Request ledger separates reported categories, rate estimate and invoice reconciliation, missing values remain unknown. Cost and correctness have separate gates.
