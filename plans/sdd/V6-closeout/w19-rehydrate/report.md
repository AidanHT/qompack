## Review resolution

**R1, major (a denied path with a space shows in section 6): CONFIRMED and FIXED in 6a70b4bf.** The store's preview of a built-in tool is the values of file_path, path, pattern, command and url joined by spaces (store/tooluseindex.go argsPreview). So `private/my secret.txt` split into tokens that no rule refuses.
- readSummary now also reads every run of consecutive words in a segment. A segment is the text between quote, bracket, comma, semicolon, pipe, redirection and `=` characters.
- Runs are read only in segments no wider than maxOneLineRunes (120, an existing constant). The store's preview is never wider than that.
- Without that bound, a first draft made TestBuild_NeverExceedsTheHostCeiling take 31.9 s. With it, the test takes 2.4-2.7 s, against 2.1-2.4 s on the b8bbc2dd gate measured through an overlay.
- New rows: Read `private/my secret.txt`, Grep `private/my secret.txt apikey`, and `cat "private/my secret.txt"`.

**R2, major (a basename selector and Glob's preview): CONFIRMED and FIXED in 6a70b4bf.**
- The judge now keeps `tails`: every withheld known path plus each of its path-segment suffixes. A relative piece that matches one is withheld. This mirrors pathSelector.weight's exact-match and suffix-match predicates.
- The substring-match predicate is deliberately not mirrored, because a substring is not a path.
- A segment's words are also joined at each space with a `/` (pieceJoin). Glob's `private deny.txt` is then judged as `private/deny.txt`, even when Qompack never recorded that file. Joins are never noted as known paths.
- A rooted piece is judged exactly. Without that, denying private/README.md would have withheld a Read of the project's own README.md. TestBuild_AnAbsolutePathIsJudgedAsTheOneFileItNames pins this.

**R3, major (section 7 shows Checkpoint.Dropped verbatim): CONFIRMED and FIXED in 00f324f1.**
- gateCheckpointDrops runs before the items are built. It covers the five checkpoint drop kinds keyed by a pointer's path: file_pointer, pointer_missing, pointer_invalid, pointer_untracked and pointer_dirty.
- A withheld entry is named by the pointer's hash while the checkpoint still holds the pointer (an untracked or dirty pointer is kept), with `restore: expand(hash=…)`. Otherwise it is named `(path withheld)`.
- The entry keeps the checkpointer's reason and drops the re_read(path) call.
- Result.Dropped, and therefore the state file and dropped(), carry the same entry. That matches the package's own requireNoLeak rule and what dropped() already does for denied paths.
- TestCheckpointPathDrops_AreTheCheckpointersOwn checks the five kinds against the real ValidatePointers and Truncate.
- normalizeDeps wraps HostPaths in sync.OnceValue, so one snapshot of the host rules serves the whole build (TestBuild_HostRulesAreEstablishedOncePerBuild).

**R4, minor (a path with no dot or separator in a multi-word preview): CONFIRMED and FIXED in 6a70b4bf.** When the host rules are established, every piece is judged whatever its shape. When they are not (fail closed), only named or path-shaped pieces are judged, as before, and runs and joins are skipped. Rows `credentials apikey` and `cat credentials` cover it. ADR §23.2 now states what the code does.
