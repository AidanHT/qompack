Reading: `e.length<=s` is JavaScript String.prototype.length on the parsed field, i.e. UTF-16
code units; a field of exactly 10,000 units is delivered whole and 10,001 is replaced. Bytes
(UTF-8) are not the unit. Code points are never more than UTF-16 units, so counting UTF-16
units is the conservative reading of 'characters' as well as the host's own.

Scope of the check: `one` runs once per hook per field (additionalContext, systemMessage,
initialUserMessage, and plain stdout). A JSON reply is parsed before any of this, so its stdout
is not itself capped; only the fields are. The per-dispatch aggregate limiter in the same bundle
(`cvn`/`hMt`, 200,000 a dispatch) serves the managed `tool.call`/`prompt.submit` contexts, not
SessionStart command hooks.
